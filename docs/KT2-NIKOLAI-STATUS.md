# Часть Николая после перехода на GigaChat

Обновлено 21 ноября 2026 года. Основной профиль: GigaChat-2-Max через https://gigachat.devices.sberbank.ru/api/v1. Другие провайдеры автоматически не выбираются.

## Что реализовано

- Обмен Authorization key на Access token через OAuth Сбера, Scope GIGACHAT_API_PERS, UUIDv4 в RqUID.
- Кэш токена в памяти, обновление перед истечением срока, общий кэш для конкурентных запросов и отменяемое ожидание обновления.
- TLS с публичным сертификатом из официальной инструкции только на уровне приложения; без отключения валидации и изменения системного хранилища.
- JSON Schema GigaChat, проверка ID источников и дословных цитат, одно исправление некорректного ответа. Дополнительная проверка моделью опциональна и по умолчанию выключена.
- Одинаковый клиент и настройки в приложении и cmd/bench; метаданные прогона содержат профиль и параметры без ключей.
- Команда cmd/llm-check для проверки доступа и отдельного синтетического примера. Запуск и переменные окружения описаны в README и .env.example.

## Фактический статус

OAuth принял предоставленный ключ. GigaChat-2-Max есть в доступных моделях, для Max выдана квота. После добавления OAuth прошёл go test ./.... Последующие запуски и проверки прекращены по прямому указанию Петра. Полный успешный benchmark GigaChat и его Accuracy/CRR не заявляются.

Ключ находится только в локальном игнорируемом .env. Коллегам нужен собственный Authorization key; скопированный проект не получает доступ автоматически.

## Что осталось перед сдачей

1. Егор передаёт зафиксированные изменения поиска и согласованные вопросы/эталоны.
2. Команда подтверждает у преподавателя k и глубину MRR.
3. После объединения изменений Пётр проводит браузерную приёмку настоящего сервера.
4. По разрешению на новые запуски выполнить свежий benchmark с GigaChat. Ответы оценить заново; старые grades не переносить. Ответственный человек подтверждает все 15 оценок, Егор формирует итоговый отчёт.

Это статус реализации, а не подтверждение успешной сдачи КТ2. Исторические отчёты Ollama и неудачные диагностики OpenRouter не являются результатами GigaChat.
