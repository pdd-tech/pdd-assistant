# Обменный прогон Патентного радара

Вход: исходные corpus.jsonl (200 рефератов) и questions.jsonl (15 вопросов). Эталоны и relevant остаются у команды-владельца; метрики качества без них не вычисляются.

Команда cmd/exchange использует существующие internal/search (BM25 и предобработка), internal/rag и GigaChat. Параметры фиксированы: k=5, k1=1.2, b=0.75; сохраняется полный рейтинг до 200 документов. В индекс и контекст входят название плюс исходный реферат; ref содержит номер и название. Порядок сохраняется из corpus.jsonl.

Отдельный профиль patents ищет аналоги по назначению или техническому принципу, поясняет ограничения частичных аналогов и отказывает при отсутствии аналогов в переданном контексте. Случайных совпадений слов недостаточно. Профиль не оценивает юридическую новизну и не использует внешние сведения. Основной профиль ПДД сохраняется.

Патентный ответ содержит text и source для каждого вывода. source обязан быть ID переданного документа; сервер подставляет номер и название. Поле quotes не запрашивается: перефразирование нельзя проверять как дословную цитату. Обоснованность просматривают по сохранённым рефератам. Строгая проверка цитат профиля pdd остаётся прежней.

До сети проверяются JSONL, непустые поля, уникальные ID. Результат содержит SHA256 исходных файлов и преобразованного корпуса, настройки и промпт, run_id, время, вопросы, ответы/отказы/ошибки, источники и полный рейтинг. Ошибка API не становится отказом; неполный прогон имеет status=failed и ненулевой код. Новый запуск выполняет реальную генерацию.

Команда из корня проекта после загрузки своего .env:

go run ./cmd/exchange -corpus ../patent-radar-exchange/input/corpus.jsonl -questions ../patent-radar-exchange/input/questions.jsonl -out ../patent-radar-exchange/results/run.json

Ключи остаются в .env, в пакет результатов не включаются. Настройки не подбираются по этим 15 вопросам, эталоны не передаются модели.
