# pdd-assistant

RAG-помощник по правилам дорожного движения для учеников автошколы.

Ученик задаёт вопрос своими словами и получает ответ со ссылками на пункты ПДД и статьи главы 12 КоАП РФ. Нужные документы находит собственный поисковый индекс BM25, а ответ по ним формулирует LLM. Админ (сотрудник автошколы) заводит учеников и смотрит журнал их запросов.

## Состояние КТ2

В этой ветке готова часть Петра: Go-шаблоны интерфейса, динамические данные, состояния ошибок/отказов, встроенные CSS/JS, локальный просмотр и тесты. Полный сервер, SQLite, корпус, BM25 и benchmark должны быть добавлены Николаем и Егором по [плану КТ2](docs/KT2-PLAN.md). Настоящий RAG в этой ветке ещё не реализован.

Требования занятия 3: 30 документов, 10 обычных вопросов (минимум 3 релевантных документа и эталон на каждый), 5 ловушек; Recall@k, MRR, Accuracy, Correct Rejection Rate. На сдаче запускаем benchmark заново. Учить собственную LLM не требуется.

## Как запустить интерфейс на localhost

Нужен Go 1.25 или новее. Из корня репозитория:

```sh
go test ./...
go run ./cmd/ui-preview
```

Открыть точный URL `http://127.0.0.1:<порт>`, напечатанный программой после успешного запуска. В верхнем баннере есть ссылки на пять экранов и все состояния. Остановить сервер — Ctrl+C. БД, API-ключ, npm и скачивание зависимостей не нужны. По умолчанию `127.0.0.1:0` поручает ОС выделить свободный порт. Не заменяйте `127.0.0.1` на `localhost`: адрес может разрешиться в IPv6 и открыть другой локальный сервис. Чтобы задать фиксированный порт, сначала проверьте его занятость (`lsof -nP -iTCP:<порт> -sTCP:LISTEN` на macOS), затем передайте `-addr 127.0.0.1:<порт>`. При занятом адресе просмотр завершится с ошибкой, не объявляя успешный запуск.

Это **просмотр на демонстрационных данных**. Формы имеют настоящие адреса POST будущего приложения, но в preview возвращают HTTP 501 с объяснением: авторизацию, сохранение и RAG подключает сервер Николая. Здесь нельзя проверить качество поиска/модели. Нужные страницы можно открыть через ссылки баннера. Демонстрационные тексты не являются корпусом или юридическими эталонами.

Дополнительные проверки и сборка:

```sh
go test -race ./...
go vet ./...
go build -o /tmp/pdd-ui-preview ./cmd/ui-preview
```

Шаблоны и ресурсы встроены в бинарник; он работает из любой папки. В ограниченной среде, если Go не может записать стандартный build cache, можно перед командой задать `GOCACHE=/tmp/nirs-go-cache` (macOS/Linux).

Интегратору: [контракт пакета internal/ui](spec/tech/ui.md). Полный server и benchmark пока не имеют исполняемых команд в этой ветке; их целевые команды и владельцы описаны в плане. После интеграции Николай добавляет сюда фактические настройки модели и инструкции запуска в разных терминалах.

## Как открыть прототип

Прототип интерфейса — статичные HTML-страницы, сервер не нужен.

1. Склонировать репозиторий: `git clone https://github.com/pdd-tech/pdd-assistant.git`
2. Открыть в браузере файл `prototype/index.html`.

На экране входа логин `admin` открывает экраны админа, любой другой логин — экраны ученика. Пароль любой.
