# pdd-assistant

RAG-помощник по правилам дорожного движения для учеников автошколы.

Ученик задаёт вопрос своими словами и получает ответ со ссылками на пункты ПДД и статьи главы 12 КоАП РФ. Нужные документы находит собственный поисковый индекс BM25, а ответ по ним формулирует LLM. Админ (сотрудник автошколы) заводит учеников и смотрит журнал их запросов.

## Как открыть прототип

Прототип интерфейса — статичные HTML-страницы, сервер не нужен.

1. Склонировать репозиторий: `git clone https://github.com/pdd-tech/pdd-assistant.git`
2. Открыть в браузере файл `prototype/index.html`.

На экране входа логин `admin` открывает экраны админа, любой другой логин — экраны ученика. Пароль любой.
