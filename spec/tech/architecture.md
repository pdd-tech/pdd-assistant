# Архитектура

## Стек

| Что | Чем | Почему |
|---|---|---|
| Язык и веб-сервер | Go, стандартная библиотека `net/http` | Команда знает Go; для нескольких страниц сторонний фреймворк не нужен |
| Интерфейс | HTML-страницы, которые сервер отрисовывает через `html/template` | Один бинарник, нет отдельной сборки фронтенда. Вёрстка берётся из `prototype/` |
| База данных | SQLite, драйвер `modernc.org/sqlite` | Один файл, не нужен отдельный сервер БД. Драйвер на чистом Go и собирается без C-компилятора, в том числе на Windows |
| Хеширование паролей | `golang.org/x/crypto/bcrypt` | Пароли не хранятся в открытом виде |
| Поиск | Свой индекс BM25 | Требование методички. Подробности в `spec/tech/rag.md` |
| LLM | Внешняя модель через OpenAI-совместимый API | См. раздел «LLM» |

## Компоненты

```
браузер
   │
   ▼
web ── auth ── store (SQLite: users, query_log)
   │
   ├── search (индекс BM25 в памяти, корпус из corpus/)
   │
   └── llm (HTTP-клиент к LLM)
```

- **web** — обработчики HTTP и шаблоны страниц.
- **auth** — вход по логину и паролю, сессии, проверка роли. Сессия — случайный идентификатор в cookie, сессии хранятся в памяти процесса. После перезапуска сервера нужно войти заново.
- **store** — работа с SQLite: пользователи и журнал запросов.
- **search** — предобработка текста, индекс BM25 и поиск top-k документов. Индекс строится в памяти при запуске сервера из файлов корпуса. Подробности в `spec/tech/rag.md`.
- **llm** — формирует промпт из вопроса и найденных документов и получает ответ модели.

## Путь запроса

1. Ученик отправляет вопрос со страницы вопроса.
2. **web** проверяет через **auth**, что пользователь вошёл и у него роль `student`.
3. **search** находит top-k документов по BM25. Значение k задано в `spec/tech/rag.md`.
4. **llm** собирает промпт: инструкция, найденные документы с номерами пунктов и вопрос. Инструкция требует отвечать только по переданным документам, ссылаться на номера пунктов и прямо говорить, если в документах ответа нет.
5. **llm** отправляет промпт модели и получает ответ.
6. **store** записывает вопрос в `query_log`.
7. **web** показывает ответ и список найденных документов.

Если модель не ответила, ученик видит найденные документы и сообщение, что ответ получить не удалось.

## Страницы

| Адрес | Метод | Роль | Что делает |
|---|---|---|---|
| `/login` | GET, POST | все | Форма входа, вход |
| `/logout` | POST | все | Выход |
| `/` | GET | student | Форма вопроса |
| `/ask` | POST | student | Ответ и найденные документы |
| `/admin/users` | GET | admin | Список учеников и форма создания |
| `/admin/users` | POST | admin | Создание ученика |
| `/admin/log` | GET | admin | Журнал запросов |

После входа ученик попадает на `/`, админ на `/admin/users`. Экраны описаны в `spec/product/scenarios.md`.

## База данных

### `users`

| Поле | Тип | Описание |
|---|---|---|
| `id` | INTEGER, PK | |
| `login` | TEXT, UNIQUE, NOT NULL | Логин |
| `password_hash` | TEXT, NOT NULL | Хеш пароля bcrypt |
| `role` | TEXT, NOT NULL | `admin` или `student` |
| `created_at` | DATETIME, NOT NULL | Когда создан |

### `query_log`

| Поле | Тип | Описание |
|---|---|---|
| `id` | INTEGER, PK | |
| `user_id` | INTEGER, NOT NULL, FK → `users.id` | Кто спросил |
| `question` | TEXT, NOT NULL | Текст вопроса |
| `created_at` | DATETIME, NOT NULL | Когда спросил |

Первый админ создаётся при запуске сервера из переменных окружения `ADMIN_LOGIN` и `ADMIN_PASSWORD`, если пользователя с таким логином ещё нет.

## LLM

Клиент работает с любым OpenAI-совместимым API (`POST {LLM_BASE_URL}/chat/completions`). Модель меняется только настройками, без изменения кода.

Кандидаты, окончательный выбор к КТ2:

| Вариант | Стоимость | Особенности |
|---|---|---|
| OpenRouter, модели с суффиксом `:free` | Бесплатно, 50 запросов в день и 20 в минуту без пополнения счёта | OpenAI-совместимый API. Список бесплатных моделей меняется, модель выбираем при настройке |
| Ollama на своём компьютере | Бесплатно | OpenAI-совместимый API (`http://localhost:11434/v1`). Нужен достаточно мощный компьютер, ответы медленнее |
| GigaChat API | Бесплатный пакет для физлиц был, его наличие нужно проверить при регистрации | Не OpenAI-совместимый, потребует отдельного клиента |

## Настройки

Все настройки задаются переменными окружения. Ключи и пароли в репозиторий не попадают.

| Переменная | Что задаёт |
|---|---|
| `ADDR` | Адрес сервера, например `:8080` |
| `DB_PATH` | Путь к файлу SQLite |
| `CORPUS_DIR` | Папка с документами корпуса |
| `ADMIN_LOGIN`, `ADMIN_PASSWORD` | Первый админ |
| `LLM_BASE_URL` | Адрес OpenAI-совместимого API |
| `LLM_API_KEY` | Ключ API |
| `LLM_MODEL` | Имя модели |

## Структура кода

Появится к КТ2:

```
cmd/server/       точка входа сервера
cmd/bench/        запуск benchmark (см. spec/tech/rag.md)
internal/web/     обработчики и шаблоны
internal/auth/
internal/store/
internal/search/
internal/llm/
corpus/           документы ПДД и КоАП
benchmark/        тестовые запросы и результаты
```

## Как проверяем

- Сценарии ученика и админа из `spec/product/scenarios.md` проходятся вручную в браузере.
- `go test ./...` проходит.
- Качество поиска проверяется benchmark, см. `spec/tech/rag.md`.
